# ASC roadmap: 216 stages from assessed general capability toward measured superhuman capability

`roadmap.jsonl` holds 12 tiers of stages, each closed by a gate task. Nothing opens until `AGI-091` is done, and each
tier needs the previous gate. These are hypotheses with independent tests, not a guaranteed route, and completing them
certifies nothing beyond each stage's measured scope.

Every stage keeps human stop controls, oversight, budgets and independent review in force. `build_roadmap.py` rebuilds the file.
